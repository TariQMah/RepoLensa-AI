# RepoLens AI

**See how a codebase fits together.**

RepoLens AI is an open-source, local-first repository explorer that turns source files and import relationships into an interactive graph. The initial release focuses on GitHub-ready TypeScript/JavaScript and C# dependency inspection, with AI explanations planned as an optional opt-in feature.

> 🚧 Early development. The first functional MVP is being developed in a feature branch.

## Goals

- Browse a repository's files and module-level dependencies in an interactive graph.
- Understand architecture without uploading private source code.
- Work locally with no account, paid API key, or hosted backend.
- Support TypeScript/JavaScript first and progressively expand C# support.
- Make graph exploration, search, and exports accessible.
